# Performance Model

## Purpose

This document defines the canonical architectural model used to
represent musical performances within Music Stewardship.

Rather than viewing a performance as a collection of independent audio
tracks, the Performance Model organizes music into a hierarchy of
Musical Units that preserve the structural, artistic, and organizational
intent of the performance.
