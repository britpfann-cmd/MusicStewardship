# Crackling Tunes v0.2 Working Update

This package updates the earlier Crackling Tunes Rosetta Stone and CSV-transition approach using the design understanding established during the September 2026 TTT ingestion exercise.

## Files

- `Crackling_Tunes_Rosetta_Stone_v2.md` — updated CT source-translation rules and their relationship to the emerging catalog model.
- `CSV_TRANSITION_ARCHITECTURE_v0.2.md` — working architecture for CSV transition layers between source representations and catalog staging.

## Intent

Reuse the successful Crackling Tunes research rather than restart it. The principal update is semantic: source representations are preserved first, and promotion into Work, Person, Ensemble, Performance, Release, Manifestation, or other concepts occurs only when the evidence supports it.

These are working design documents, not a final ontology or database schema.
